Clockwork Kitchen — the whole kitchen is a clock face and every order is a hand you race around it. Pick ingredients from the bottom rail, boil noodles in the pot, fry eggs in the pan, build dishes on the central plate, and ring the service bell before the shift timer runs out. Four original recipes, order patience, combos, burnt food, and a 120-second shift with a 120-coin target.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static HTTP server and open `game/index.html`. No build step, no network requests. Play with mouse and keyboard (keys 1-6 grab ingredients, Space serves, R restarts).
